# 🌟 Fauzan Muhammad Iftitah — Portfolio Website

An interactive, modern, and responsive personal portfolio website showcasing game development projects, UI/UX designs, desktop applications, and software engineering work.

---

## 🚀 Live Demo & Repository
- **Repository URL**: [https://github.com/FauzanMuhammadI/Web-Profile-Fauzan](https://fauzanm.vercel.app)

---

## ✨ Features

- 🌌 **Interactive Particle Canvas**: Dynamic background particles responding to mouse movement.
- 💎 **Glassmorphism & Neon Glow**: Modern dark aesthetic with sleek glass cards and ambient glow gradients.
- 🎯 **3D Card Tilt Effects**: Interactive hover depth using vanilla JavaScript physics.
- 📱 **Fully Responsive Design**: Optimized layouts across desktops, tablets, and mobile devices.
- 📊 **Featured Projects Showcase**: Detailed views and screenshot galleries for games, machine learning apps, and UI/UX projects.
- 📜 **Smooth Navigation & Scroll Progress**: Header navigation with active spy links and real-time scroll progress bar.
- 📧 **Interactive Contact Section**: Contact form and direct links to social profiles.

---

## 🛠️ Built With

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom CSS variables, Grid/Flexbox layouts, glassmorphism filters, and smooth keyframe animations.
- **JavaScript (Vanilla ES6+)**: Interactive components, canvas particle animation engine, and DOM manipulation.
- **Phosphor Icons**: Vector icon library for modern UI accents.
- **Google Fonts**: `Outfit`, `Plus Jakarta Sans`, and `JetBrains Mono`.

## 💻 Getting Started

To run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/FauzanMuhammadI/Web-Profile-Fauzan.git
   ```

2. **Navigate into the project directory**:
   ```bash
   cd Web-Profile-Fauzan
   ```

3. **Launch the site**:
   - Double-click `index.html` to open it in your browser, or
   - Use VS Code **Live Server** extension, or
   - Run a local static server with Python / Node.js:
     ```bash
     # Using Python
     python -m http.server 3000
     
     # Using npx serve
     npx serve .
     ```
